# Citation integrity audit

## Identity

- Open the cited source and match publisher/author, exact title, date, version, and stable identifier.
- Resolve DOI, PMID, trial registry, filing, standard, or product code against the authoritative registry when one exists.
- Check corrections, errata, retractions, withdrawals, and later versions.
- Do not infer bibliographic details from a URL slug, search snippet, or another paper's reference list.

## Placement and support

- Put the citation immediately after the sentence or paragraph it supports.
- Split sentences that contain several claims supported by different sources.
- Verify quotations word for word and keep them short; otherwise paraphrase accurately.
- Never let a citation to background context appear to support a numerical, causal, safety, or current-status claim it does not contain.

## Link integrity

- Prefer the stable official or publisher page over tracking, redirect, aggregator, or search-result URLs.
- Remove affiliate and tracking parameters when they are unnecessary for identity.
- Check that the link resolves to the intended document rather than a homepage, related article, or replacement product.
- State when only an abstract, snippet, cached copy, or secondary description was available.

## Final factuality pass

Read the answer sentence by sentence. For each externally verifiable material sentence, either:

1. confirm it from inspected evidence;
2. label it as calculation, inference, scenario, or uncertainty; or
3. remove or narrow it.

Then verify every named source exists and every user-visible citation supports the nearby claim. This pass is separate from drafting so fluent prose does not hide unsupported details.
