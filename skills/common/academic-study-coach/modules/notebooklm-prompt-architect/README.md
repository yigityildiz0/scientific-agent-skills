# NotebookLM Prompt Architect

A opencode skill for creating high-quality NotebookLM prompts for study, exams, reports, flashcards, quizzes, slide decks, infographics, audio/video overviews, and source-grounded chat.

## What it does

- Rewrites rough NotebookLM requests into structured prompts.
- Optimizes prompts for dense, no-fluff, source-cited educational outputs.
- Includes templates for NotebookLM artifacts.
- Includes study/exam playbooks for health sciences, physiotherapy, medical-style lectures, and slide/PDF-heavy courses.

## Install in Claude.ai

1. Open Claude.ai.
2. Go to Settings / Features / Skills.
3. Upload the ZIP file.
4. Enable the skill.
5. Start a new chat and ask something like:
   - "NotebookLM'ye bu PDF için sınav odaklı prompt yaz."
   - "NotebookLM için flashcard promptu oluştur."
   - "NotebookLM slide deck için gereksiz kelimesiz prompt yaz."

## Install in opencode

Unzip into one of these locations:

- Personal: `~/.config/opencode/skills/notebooklm-prompt-architect/`
- Project: `.opencode/skills/notebooklm-prompt-architect/`

The folder must contain `SKILL.md` directly inside it.

## Safety

This skill contains no scripts and makes no network calls. It is instruction/reference only.
