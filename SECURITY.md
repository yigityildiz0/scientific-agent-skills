# Security

Agent Skills are executable instructions. Review a skill and its scripts before granting tool access or trusting a repository.

- Do not paste secrets, credentials, patient data, unpublished sequences, customer data, or private source code into an unapproved service.
- Installation, network access, package changes, privileged commands, deletion, publication, and external messages require the user's explicit authorization.
- Prefer isolated environments, pinned versions, checksums, dry runs, and reversible changes.
- Report a security problem privately through GitHub's security-advisory flow when available. Do not include live credentials or sensitive data in an issue.
