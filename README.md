# Scientific Agent Skills

Seventeen focused Agent Skills for reproducible scientific research: problem selection, literature review, experimental design, R/RStudio, biostatistics, DESeq2, ggplot2, molecular genetics, single-cell analysis, scVI-tools, nf-core/Nextflow, Quarto, and academic presentations.

The packages use the portable `SKILL.md` format. They are format-compatible with Claude Code, OpenAI Codex, and OpenCode; scientific software, data access, and tool execution still depend on the user's environment. Compatibility is not a claim that every dependency was executed on every platform.

## Download all 17

[⬇ Claude Code](https://github.com/yigityildiz0/scientific-agent-skills/releases/latest/download/scientific-agent-skills-claude.zip) · [⬇ OpenAI Codex](https://github.com/yigityildiz0/scientific-agent-skills/releases/latest/download/scientific-agent-skills-codex.zip) · [⬇ OpenCode](https://github.com/yigityildiz0/scientific-agent-skills/releases/latest/download/scientific-agent-skills-opencode.zip)

Extract the matching bundle into your home or project root. It already contains `.claude/skills`, `.agents/skills`, or `.opencode/skills`. Prefer installing only the skills you need.

## Start here

1. Open the [searchable catalog](https://yigityildiz0.github.io/scientific-agent-skills/) or use the table above.
2. Download one skill ZIP or the platform bundle.
3. Read the skill before granting tools or installing scientific packages.
4. Ask naturally, for example: `Use scientific-literature-review to build a reproducible PubMed search and evidence table for ...`

## Reproducibility and safety

- Raw data must stay immutable; record versions, parameters, seeds, identifiers, and checksums.
- Installation, downloads, external services, privileged changes, deletion, and publication require explicit user approval.
- Clinical, biosafety, IRB/IBC/IACUC, GLP/GMP, and regulatory decisions remain with qualified humans and institutions.
- License and provenance status differs by skill. Read [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) before redistribution.
