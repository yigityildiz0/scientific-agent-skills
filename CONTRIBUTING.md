# Contributing to Scientific Agent Skills

Contributions are welcome when they improve a skill, add verified provenance, or fix platform guidance.

1. Keep each skill self-contained with `SKILL.md` at its root.
2. Use lowercase hyphenated names and make the folder name match the frontmatter `name`.
3. Document the upstream repository, exact revision, license, dependencies, external services, and mutating commands.
4. Never commit secrets, private data, generated caches, or downloaded research datasets.
5. Update both English and Turkish catalog descriptions.
6. Run the repository validator before opening a pull request.

For license corrections or takedown requests, open a `provenance` issue and include evidence.
